# 03 算法规格（A5 algorithm-solver 产出；A6 按此实现）

## 1. 问题2：实际赔付金额回归

### 1.1 数据与目标
- 训练：clean_附件1（11167×31 特征 + payment_real）；预测：clean_附件2（2792 条）。
- 目标变换：z = log1p(y)（y 右偏，均值 292.2 / 中位 200.2），预测端 expm1 还原，保证非负。

### 1.2 候选模型与选型
| 模型 | 配置要点 | 角色 |
|---|---|---|
| 基线0 | 按索赔金额十分位的层中位数预测 | 锚点（衡量特征增益） |
| LightGBM | objective=regression on log1p；学习率 0.05、叶 31、深 −1、特征/袋抽样 0.8、早停 200 轮（折内 15% 验证） | 主模型（类别特征原生，NaN 原生） |
| XGBoost | hist、同量级参数、类别序数编码 | 对比 |

选型准则：5 折 CV 的 OOF SMAPE 最小者为主模型；论文同时报告四指标。

### 1.3 交叉验证与指标
- 分层不适用（回归）→ 普通 5 折 KFold，seed=2025，折间共享同一划分（与 Q3 对齐便于路线对比）。
- 指标（原始金额尺度）：
  - MAE = (1/n)Σ|y−ŷ|
  - RMSE = √[(1/n)Σ(y−ŷ)²]
  - SMAPE = (1/n)Σ( 2|y−ŷ| / (|y|+|ŷ|) )（对称相对误差，对量级稳健）
  - WMAPE = Σ|y−ŷ| / Σ|y|（加权绝对百分比误差）
- 测试预测：5 折模型对 log 空间预测取平均后还原（折平均降低方差）。

### 1.4 防泄漏纪律（决策 D07）
- 类别特征用 pandas category 原生传入 LightGBM；高基数 ID 用训练+测试合并词表频次编码；
- 禁止任何形式的全局目标编码；早停验证取自折内，不用测试集调参。

## 2. 问题3：风险标注分类

### 2.1 两条路线（题面必答②）
- **路线a 直接分类**：以 Q1 标签为监督，31 特征直接训练多分类。
- **路线b 先回归后标注**：以 Q2 的 ŷ 代入 Q1 规则 L = rule(c, ŷ) 得标签。附件1 上用 OOF 的 ŷ 模拟"预测场景"评估；附件2 上对最终模型预测。
- 评价：路线a 用分层 5 折 OOF macro-F1；路线b 用 OOF 标签一致率 + macro-F1（把规则标签当预测、Q1 标签当真值）；两者同折同划分，可直接对比。
- 提交策略：OOF 实证优者作为 Result 主方案（若 macro-F1 差距 <0.02，取与 Q1 规则一致性更高的路线b，理由：与问题1规则自洽）。

### 2.2 严重不均衡处理（题面必答①，严重超额占比仅 1.34%）
采用**三级组合**：
1. **代价敏感（class weight）**：LightGBM 类别权重 = 反频率归一（n/(3·n_k)），主要手段；
2. **先验/阈值校正**：对 OOF 概率搜索类偏置 b=(b_合理,b_偏高,b_严重)，argmax_c[log p_c + b_c]，目标 macro-F1 最大，同时校验预测占比偏离 Q1 先验不超过 ±2pp；
3. **过采样与 focal loss 的取舍（论文论述用）**：
   - SMOTE 类方法：本数据高基数类别特征多、特征混合连续/离散，SMOTE-NC 生成样本易落入低密度区造成标签噪声；且树模型对复制/插值样本的增益有限（实验文献共识），故不采用为主方案，仅作对比说明；
   - Focal Loss：面向密集检测器的难例加权，可直接用于多分类梯度提升（如 focal 版 softmax），但本任务"严重超额"并非难例主导而是**先验极度失衡**，代价敏感+先验校正更对症；作为可扩展方向论述。
   - 补充：分层抽样保证每折类别比例一致；macro-F1 作主指标避免 accuracy 被多数类稀释。

### 2.3 评估输出
混淆矩阵（3×3）、各分类 precision/recall/F1、macro-F1、预测标签分布 vs Q1 先验（合理≥85%、严重<3% 软约束校验）。
